# Social link
http://192.168.122.111/

## How to get flag
Inspect social link elements and change value of site params ex) `site=whatever`
```
<a href="index.php?page=redirect&amp;site=facebook" class="icon fa-facebook"></a>
```

## Vulnerability
Attacker can make fake link dynamically by changing site value.

## How to Fix
Use static link generated by back-end, instead of dynamic link.
```
<a href="https://www.facebook.com/42born2code/" class="icon fa-facebook"></a>
```
