# Darkly

## Overview
When we develop our website, we have no clue regarding the risks exposed to in the World Wide Web. `Darkly` is one of école 42 project in web branch, which lets us know how fragile our website is and how much the framework is doing for us.

Strongly recommanded to read [OWASP - web security testing guide](https://owasp.org/www-project-web-security-testing-guide/stable/) before starting the project.

## Launch Darkly_i386.iso vm on ubuntu 18.04
```
sudo apt-get install qemu
sudo apt-get install virt-manager
sudo virt-manager
```
