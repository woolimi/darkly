# Social link

## How to get flag
Inspect social link elements and change value of `site` params. For example, `site=whatever`
```
<a href="index.php?page=redirect&amp;site=whatever" class="icon fa-facebook"></a>
```

## Vulnerability
Attacker can make fake link dynamically by changing site value.

## How to Fix
Use static link generated by back-end, instead of dynamic link.
```
<a href="https://www.facebook.com/42born2code/" class="icon fa-facebook"></a>
```
